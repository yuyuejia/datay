数据集成

Data Integration

  • 支持 MySQL / PostgreSQL / Oracle / Doris / ClickHouse / DuckDB 等十余种数据源
  • 可视化拖拽画布编排 ETL 数据流，也可 JSON 配置文件一键跑任务
  • 全量同步、增量同步、MySQL CDC / PostgreSQL CDC 实时同步
  • 自动建表（DDL 转换），源表改字段自动同步到目标
数据集成指南 ETL 组件 场景案例

数据建模

Data Modeling

  • 支持 Star Schema / Snowflake 维度建模，普通维度 / 层级维度 / 时间维度
  • 事实表字段关联维度，自动携带业务语义
  • 指标管理：原子指标 / 衍生指标，业务限定统一口径
  • 内嵌列存 DuckDB，单机跑出分布式数仓性能
维度建模 指标管理 Web 平台

数据开发

Data Development

  • 基于 Vue Flow 的拖拽式 ETL 画布，节点连线编排数据流，双击配置参数
  • 丰富的组件库：输入 / 处理 / 输出 / 路由组件，覆盖 CDC、SQL 处理、Doris 加载
  • 多类型任务：ETL、SQL、Shell、DAG 工作流、Demo
  • DAG 工作流编排，执行时自动拓扑排序，按序调度子任务
任务设计与开发 组件库 场景案例

任务调度

Job Scheduler

  • Cron 定时调度，Quartz 引擎精准到秒，支持动态上下线
  • 依赖调度：父子任务自动拓扑排序，父任务成功后触发子任务
  • 手动触发、暂停 / 恢复、失败重试，实例全生命周期监控
  • 调度 master 与执行 worker 可分离部署，Redis 队列分发与 Leader 选举
任务调度与实例 ETL 状态管理 部署模式

快速开始

克隆、构建、启动，10 分钟见到完整平台。启动时自动预置一整套电商示例，登录即用。

  • 数据源：电商数仓（DuckDB）
  • 维度表：日期 / 客户 / 门店 / 商品 / 品牌 / 品类 / 时间
  • 事实表：销售订单、订单明细、会员
  • 指标：销售额、销量、毛利、毛利率、客单价等 12 个
跟着实战指南做一遍 嵌入 Core 引擎 
# 1. 克隆仓库
git clone https://cnb.cool/yuyuejia/datay

# 2. 构建项目
cd datay
mvn clean package -DskipTests

# 3. 启动（单机模式，调度 + 执行合一）
java -jar datay-web/target/*.jar \
  --DATAY_AI_API_KEY=sk-xxxxxxxxx

# 4. 打开 http://localhost:8080
#    默认账号 admin / admin
