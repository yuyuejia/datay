# DataY 帮助中心

> DataY 是一套**轻量数据平台**：一个 JAR、内嵌 DuckDB，在 **2 核 4G** 的机器上就能跑通
> **数据集成 → 数据建模 → 数据开发 → 任务调度 → 数据应用** 的完整链路。

本帮助中心集中了 DataY Core（数据集成引擎）与 DataY Web（可视化数据平台）的文档，
你可以用顶部搜索框按关键字检索，或从左侧目录逐级浏览。
