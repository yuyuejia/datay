# 分析看板「大屏 P0」技术方案

> 目标：在现有分析看板（spec v2）之上，用最小代价补齐「像素级版面 + 科技风皮肤 + 多图层地图」，
> 使 1920×1080 的目标稿（领导驾驶舱·学生管理主题）可复刻到 80% 以上。
>
> 约束：不破坏现有 spec；`version` 仍为 2，新增字段全部 optional；不改 REST 契约（spec 仍是 JSON 文本）。

---

## 1. 范围

### 1.1 本期做（P0）

| 编号 | 能力 | 对应目标稿元素 |
| --- | --- | --- |
| P0-1 | 画布：贴边（padding/gap 可配）、像素定位、组件叠放（zIndex） | 三栏贴边面板、地图上的浮层、底图叠放 |
| P0-2 | 组件样式系统 `widget.style`：卡片/标题/内容区/KPI/图表开关 | 透明描边卡片、渐变标题栏、角标装饰 |
| P0-3 | 大屏主题预设 + token（主色/序列色/字体/地图配色） | 深蓝科技风整体换肤 |
| P0-4 | 新组件 `title`（大屏标题栏）、`clock`（日期时间） | 顶部标题栏、左上日期 |
| P0-5 | KPI 增强：标签/图标/单位字号/数字动效/数字字体 | 159800 大字、三联指标、奖助贷 3×2 |
| P0-6 | 地图多图层：region + effectScatter + lines，支持逐层数据集 | 省份填色 + 涟漪点 + 飞线汇聚重庆 |
| P0-7 | 图表样式预设（渐变柱/面积渐变/发光线/轴与图例皮肤） | 招生增长组合图、年龄分布柱 |
| P0-8 | 渲染修正：DPR 清晰度、`setOption` 增量合并 | 4K 不糊、刷新不闪 |

### 1.2 本期不做（明确后置）

- 素材上传/素材市场、SVG 装饰组件（P1，依赖文件资产表）
- 多页轮播、图表联动、省市下钻（P1）
- 同环比等派生计算、WebSocket 推送（P1）
- 3D、旋转、时间轴动画、自由曲线边框（P2）

> 结论：**「装饰素材」用 CSS 预设替代，「新组件」只加 title/clock 两种纯展示组件**，这两刀把 P0 的工程量砍掉约 40%，同时不影响目标稿还原度。

## 2. 总体设计

```
spec(JSON)
  ├─ layout.screen.canvas        ← 画布：grid / px 双模式
  ├─ layout.screen.tokens        ← 主题 token（CSS 变量 + ECharts 主题）
  ├─ widgets[].layout/zIndex     ← 定位与层级
  ├─ widgets[].style             ← 皮肤（纯视觉，不进数据链路）
  ├─ widgets[].chart.layers      ← 地图多图层
  └─ widgets[].props             ← title/clock 的文本与格式

渲染分层（自下而上）：
  DashboardStage(fit/scale) → DashboardCanvas(layout) → DashboardWidget(style shell)
      → EChart / KpiWidget / TitleWidget / ClockWidget / Table / Pivot
```

设计原则：

1. **样式与数据解耦**：`style` 只影响 DOM 与 ECharts option 的默认值，不参与查询、聚合、下钻。
2. **默认值兜底**：任何新字段缺失时，行为与当前版本完全一致（回归基线）。
3. **白名单归一化**：服务端对 `style` / `tokens` / `props` 做白名单裁剪与边界钳制，未知键丢弃。
4. **前端可降级**：老数据在新前端渲染结果不变；新数据在旧前端忽略 `style`（未知字段被保留但不渲染）。

### 3.2 `layout.screen.canvas`

| 字段 | 类型 | 默认 | 边界 | 说明 |
| --- | --- | --- | --- | --- |
| `unit` | `grid \| px` | `grid` | 枚举 | `grid` 沿用 24 列；`px` 为画布绝对像素 |
| `padding` | int | `16` | 0..64 | 画布内边距，`0` 即贴边 |
| `gap` | int | `12` | 0..48 | 仅 `grid` 模式生效 |

**坐标定义（px 模式）**：`widget.layout = {x,y,w,h}` 为相对「画布内容区」（已扣除 padding）的像素值；
`w ∈ [40, W-2p]`、`h ∈ [20, H-2p]`、`x + w ≤ W-2p`、`y + h ≤ H-2p`（`W/H` 为设计分辨率，`p` 为 padding）。

> 为什么不用百分比：目标稿里 400/520/360 这种宽度无法被 24 栅格整除，栅格始终差 2~6px；且面板内子块需要精确对齐。

**兼容策略**：`unit=grid` 时 `normalizeLayout` 行为完全不变；老看板不写 `canvas` 即为 `grid + 16/12`。

### 3.3 主题：`themePreset` + `tokens`

```jsonc
"themePreset": "tech-blue",   // tech-blue | tech-cyan | gov-red | ink-dark | custom
"tokens": {
  "primary": "#2fa8ff",
  "secondary": "#1de9b6",
  "accent": "#ffd54f",
  "text": "#d8ecff",
  "textSecondary": "#7c9cb9",
  "surface": "rgba(9,26,48,0.55)",
  "border": "rgba(47,168,255,0.35)",
  "palette": ["#2fa8ff", "#1de9b6", "#ffd54f", "#ff7a45", "#b37feb", "#36cfc9"],
  "fontFamily": "system",           // system | number-digital | number-condensed
  "map": { "area": "#0b3a5b", "border": "#2fa8ff", "emphasis": "#1a7fbf", "label": "#cfeaff" }
}
```

- `themePreset` 在**前端** `theme-presets.ts` 里解析成一组 token；`tokens` 为其覆盖项（服务端只存名字与覆盖值，不重复存预设）。
- 渲染时将 token 写入看板根节点的 CSS 变量（`--dash-primary` 等），同时用于生成 ECharts 主题与地图配色。
- `theme`（light/dark）保留，作为基础明暗底色；`tech-*` 预设默认 `dark`。

### 3.4 `widget.zIndex` 与 `widget.style`

`zIndex`：int，0..999，默认 0。仅 `unit=px` 时允许组件重叠；`grid` 模式仍禁止重叠（保持现状）。

`style`（全部可选，白名单裁剪）：

```jsonc
{
  "card": {
    "preset": "none",                       // none | tech-corner | tech-frame | bracket
    "fill": { "type": "none" },             // none | color | gradient；color 带 color，gradient 带 {from,to,angle}
    "opacity": 1,                           // 0..1
    "border": { "width": 1, "color": "#1b5c8a", "style": "solid", "radius": 4 },
    "shadow": { "x": 0, "y": 0, "blur": 16, "spread": 0, "color": "rgba(0,180,255,0.25)" },
    "padding": 8,                           // 0..48
    "backdropBlur": 0                       // 0..20
  },
  "title": {
    "show": true,
    "icon": "chart-line",                   // fontawesome 名称，^[a-z0-9-]{1,40}$
    "fontSize": 15, "fontWeight": 600, "color": "#7fe3ff",
    "align": "left",                        // left | center | right
    "height": 34, "letterSpacing": 0,
    "background": "none",                   // none 或合法颜色
    "decoration": "gradient-underline"      // none | underline | gradient-underline | left-bar
  },
  "body": { "padding": 4 },                 // 0..32
  "kpi": {
    "label": "学生总数",                     // ≤ 40 字
    "icon": "user-graduate",
    "layout": "label-top",                  // label-top | label-left | value-only
    "value": { "fontSize": 56, "color": "#eaf6ff", "fontFamily": "number-digital", "bold": true, "letterSpacing": 1 },
    "unit": { "text": "人", "fontSize": 16, "color": "#8fb6d6" },
    "animate": true,
    "decimals": 0
  },
  "chart": {
    "preset": "tech",                       // tech | minimal | dark
    "gradient": true,                       // 柱/面积渐变
    "glow": true,                           // 线条发光
    "showAxis": true, "showLegend": true, "showLabel": false
  }
}
```

`fill` 结构与看板背景保持一致（`type/color/gradient`），复用同一套颜色校验。

### 3.5 地图图层：`chart.layers`

| kind | 必填字段 | 其余字段 | 渲染 |
| --- | --- | --- | --- |
| `region` | `valueField` | `agg`（默认 sum）、`datasetId` | `series-map` + `visualMap` |
| `effectScatter` | `lngField`、`latField` | `nameField`、`valueField`、`symbolSize`、`color`、`datasetId` | `series-effectScatter`（`coordinateSystem:'geo'`） |
| `lines` | `fromLngField`、`fromLatField`、`toLngField`、`toLatField` | `valueField`、`color`、`curveness`、`effect`、`datasetId` | `series-lines`（`coordinateSystem:'geo'`） |

规则：

- `layers` 最多 4 个，`region` 最多 1 个且必须在第 0 位（没有则自动补默认 region 层）。
- 每层可指定 `datasetId`，缺省用 `widget.datasetId`；引用的数据集必须在 `datasets[]` 中声明。
- 只在 `chart.type = 'map'` 时允许 `layers`。
- 字段存在性校验：当数据集有字段缓存时，逐层校验字段是否存在（与 `encode` 校验同源）。

### 3.6 新组件 `title` / `clock`

```jsonc
{ "id": "t1", "type": "title", "layout": {"x":0,"y":0,"w":1920,"h":72},
  "props": { "text": "领导驾驶舱", "subText": "学生管理主题", "align": "center", "frame": "tech-frame" },
  "style": { "title": { "fontSize": 30, "color": "#cfeaff", "letterSpacing": 4 } } }

{ "id": "c1", "type": "clock", "zIndex": 1, "layout": {"x":24,"y":16,"w":260,"h":32},
  "props": { "format": "date-week" },
  "style": { "title": { "fontSize": 14, "color": "#9fd3ff" } } }
```

- 两种组件都**不绑定数据集**，不参与取数、不参与聚合、不参与下钻；也不渲染组件 header。
- `title/clock` 复用 `style.title` 作为文本样式（字号/颜色/字体/对齐/字距）。
- `title.frame`：`none` | `tech-frame` | `bracket`，控制标题栏外框（与 `style.title.decoration` 的文字装饰线区分）。
- `clock.format`：`date` | `datetime` | `time` | `date-week`；内部用 dayjs（已有依赖）。
- `title` 最多 120 字，`subText` 最多 60 字。

### 3.7 兼容性矩阵

| 场景 | 结果 |
| --- | --- |
| 老 spec（无新字段） | 归一化后与当前完全一致，回归用例保护 |
| 新 spec + 旧前端 | 新字段被忽略（`type` 为 `title` 的组件会落到「不支持类型」兜底，需同版本发布） |
| `unit=px` + `zIndex=0` | 允许重叠但不叠层，按数组顺序渲染 |
| 新字段非法值 | 服务端回落默认值（颜色非法→默认色，数值越界→钳制） |

> 注意：新增组件类型属于**前后端同步发布**项；需在发布说明中标注"看板设计器与查看器需同版本"。

### 4.2 样式解析（新增 `shared/dashboard/widget-style.ts`）

职责：`WidgetStyle + ThemeTokens → { cardClass, cardStyle, headerStyle, bodyStyle, titleIcon }`，
所有值来自白名单归一化后的对象，禁止拼接任意 CSS 字符串。

```ts
export function resolveCardStyle(style?: WidgetStyle) {
  const card = style?.card;
  const css: Record<string, string> = {};
  const cls: string[] = [];
  if (!card) return { css, cls };

  const fill = card.fill;
  if (fill?.type === 'none') css.background = 'transparent';
  if (fill?.type === 'color' && fill.color) css.background = fill.color;
  if (fill?.type === 'gradient' && fill.gradient) {
    const { from, to, angle } = fill.gradient;
    css.background = `linear-gradient(${angle}deg, ${from}, ${to})`;
  }
  if (card.border) {
    const { width, style: borderStyle, color, radius } = card.border;
    css.border = `${width}px ${borderStyle} ${color}`;
    if (radius != null) css.borderRadius = `${radius}px`;
  }
  if (card.shadow) {
    const { x, y, blur, spread, color } = card.shadow;
    css.boxShadow = `${x}px ${y}px ${blur}px ${spread}px ${color}`;
  }
  if (card.backdropBlur) css.backdropFilter = `blur(${card.backdropBlur}px)`;
  if (card.opacity != null) css.opacity = String(card.opacity);
  if (card.preset && card.preset !== 'none') cls.push(`dash-card--${card.preset}`);
  return { css, cls };
}
```

预设边框（`tech-corner` / `tech-frame` / `bracket`）写在 `dashboard-theme.scss`：

- 角标：`::before/::after` + `border-image` 或四条 `linear-gradient` 定位线，**不使用 clip-path**（clip-path 会裁掉阴影与子元素溢出）。
- 需要裁角效果时，用内层 `.dash-card__clip` 承载 `clip-path`，外层保留阴影。

### 4.3 画布：grid / px 双模式

**`shared/dashboard/designer/grid-layout.ts`** 新增：

**`DashboardCanvas.vue`**

- 从 `spec.layout` 读取 `canvas`；`grid` 模式保持 `display:grid`；`px` 模式改为 `position:relative` + 子项 `position:absolute; left/top/width/height`。
- `padding` 从 `canvas.padding` 取（不再固定 16px），`gap` 从 `canvas.gap` 取。
- 子项加 `z-index: widget.zIndex`（仅 >0 时输出）。

**`DesignerCanvas.vue`**

- 拖动/缩放：`unit=px` 时位移直接用 `(clientX - startX) / scale`，不做栅格取整；落点用 `layoutFromPixelPoint`。
- `unit=px` 时**不调用 `compactLayouts`**（不能把用户摆好的位置压回去）。
- 工具栏增加「置顶/置底」（交换 zIndex），选中框增加 `z-index` 提示。
- 拖拽预览（`dropPreviewStyle`）当前按「列宽/行高」计算，px 模式需直接用 `x/y/w/h` 输出 `left/top/width/height`。
- 网格背景线：`px` 模式改为 8px 点阵或直接隐藏（`canvas.gap < 4` 时隐藏）。

**`analysis-dashboard-designer.component.ts`**

- `onLayoutChange` / `onResize` / `addWidget` 按 `unit` 分支：px 模式直接 `applyLayouts`，不 `moveLayout/resizeLayout`。
- 新增 `setZIndex(id, delta)`、`bringToFront/sendToBack`。
- 画布设置里新增「布局单位 / 内边距 / 间距」。

### 4.4 渲染层修正

**`EChart.vue`**

1. **清晰度**：`echarts.init(el, theme, { devicePixelRatio: (window.devicePixelRatio || 1) * scale })`。
   `scale` 由 `DashboardStage` 插槽下发 → `DashboardCanvas` → `DashboardWidget` → `EChart`；
   `stretch` 模式横向/纵向比例不同，取 `Math.max(scaleX, scaleY)`。
   缩放变化超过 0.05 时（防抖 300ms）重建实例；否则只 `resize()`。
2. **增量更新**：`chart.setOption(option, { notMerge: false, replaceMerge: ['series', 'xAxis', 'yAxis', 'geo', 'visualMap'] })`，
   避免每次自动刷新全量重绘导致飞线/涟漪闪断。
3. 图表类型切换时通过 `:key="widget.id + ':' + chartType"` 强制重建，避免 merge 残留旧 series。

> 现状是 `setOption(option, true)`（notMerge），必须改，否则 P0 的动画类效果无法稳定。

**`DashboardWidget.vue`**

- 新增 props：`scale?: number`、`datasetData?: Record<string, DatasetResult>`（供地图图层取数）、`tokens?: ThemeTokens`。
- 结构改为：`<div class="dashboard-widget-card" :class="[...]" :style="cardStyle">` + header + body。
- header 支持图标、装饰线、对齐；`style.title.show === false` 时不渲染 header。
- 组件分发：新增 `TitleWidget` / `ClockWidget` 分支；`title/clock` 与 `html` 一样不渲染 header（`showHeader` 计算需覆盖）。

**`DashboardCanvas.vue`**

- 透传 `scale`、`datasetData`、`tokens`；`DashboardStage` 的插槽已提供 `scale`。

```ts
// 2) region 层：有叠加层时用 geoIndex 绑定，避免重复绘制
option.series.push({
  type: 'map', ...(hasOverlay ? { geoIndex: 0 } : {}), map: mapName,
  data: regionData, ... 
});
option.visualMap = { seriesIndex: mapSeriesIndex, ... };

// 3) effectScatter 层
option.series.push({ type: 'effectScatter', coordinateSystem: 'geo', data: points,
  symbolSize: layer.symbolSize ?? [8, 24], rippleEffect: { brushType: 'stroke', scale: 3 },
  itemStyle: { color: layer.color } });

// 4) lines 层
option.series.push({ type: 'lines', coordinateSystem: 'geo', polyline: false,
  data: flows.map(f => ({ coords: [[fromLng, fromLat], [toLng, toLat]], value: f.value })),
  lineStyle: { color: layer.color, curveness: layer.curveness ?? 0.2, width: 1, opacity: 0.7 },
  effect: { show: true, period: 4, trailLength: 0.3, symbolSize: 4, ...layer.effect } });
```

要点：

- `visualMap.seriesIndex` 必须指向 map series，否则会同时给涟漪点着色。
- 图层数据按 `layer.datasetId ?? widget.datasetId` 从 `datasetData` 取；`DashboardWidget` 需要新增该 prop。
- `buildEchartsOption(widget, result, datasetData?)` 增加第三个参数（仅地图图层使用）；`DashboardWidget` 的 `computed option` 传入即可，其余图表不受影响。
- 无 `layers` 时**完全走现有逻辑**（回归保护）。
- 地图配色优先取 `tokens.map`，未配置时回落到 `echartsOption` / 主题。

> **技术验证项（0.5 人日）**：`series-map.geoIndex + visualMap` 组合下区域着色是否生效。
> 若不生效，兜底方案：不建 map series，按阈值把颜色算进 `geo.regions[].itemStyle` 逐区渲染。

## 6. 关键实现细节与坑

1. **坐标换算必须只有一个入口**
   舞台用 `transform: scale()`，所有鼠标事件都要先除以 `scale`。目前 `DesignerCanvas` 里散落着 `scale` 除法，
   P0 抽一个 `toCanvasPoint(event, el, scale)`，否则 px 模式下的拖动会有 1~3px 漂移。

2. **`compactLayouts` 在 px 模式必须禁用**
   它会把组件往上压。px 模式一旦误用，用户摆好的版会"自动跑位"，这是最容易被反馈的 bug。

3. **ECharts 的 merge 与 series 数量变化**
   `replaceMerge: ['series', ...]` 能清掉多余 series，但 `xAxis/yAxis` 从对象变数组时仍可能残留；
   图表类型切换用 `:key` 重建最稳。

4. **DPR 重建的代价**
   `devicePixelRatio` 只能在 `init` 时指定，缩放变化必须 dispose + init。要防抖 + 只在变化 > 0.05 时重建，
   否则拖窗口会明显卡顿。

5. **地图三图层的 zlevel 与性能**
   `effectScatter`（涟漪）和 `lines`（飞线）是动画层，必须设 `zlevel: 1` 与地图分离，否则区域重绘会带着动画层一起重绘，帧率掉一半。
   建议同时限制：涟漪点 ≤ 200、飞线 ≤ 100。

6. **`visualMap.seriesIndex` 漏配**
   不指定时 visualMap 会给所有 series 上色，涟漪点会变成地图渐变色。必须显式指定 map series 的索引。

7. **透明卡片 + backdrop-filter 的性能**
   大屏上 20+ 个卡片同时 `backdrop-filter: blur()` 会掉帧。默认 `backdropBlur = 0`，只在必要时开启。

8. **字体许可与包体**
   `number-digital` 字体需要自托管 woff2（OFL 协议，约 30~60KB/个），放 `content/fonts/`，在 `dashboard-theme.scss` 里 `@font-face`；
   不要引 CDN（内网大屏通常无外网）。
