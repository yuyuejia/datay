# 数据质量

DataY 的数据质量模块包含 **质量规则** 和 **检核任务** 两部分：

- 质量规则：维护表级、字段级检查规则，系统预置常用规则，也支持自定义规则。
- 检核任务：选择一个数据源和一张表，绑定若干规则后立即执行，结果写入文件存储。

## 一、质量规则

进入 **数据质量 → 质量规则**。

系统预置规则覆盖：

- 表级：表行数下限、表行数范围、组合字段唯一、表级自定义 SQL
- 字段级：非空、唯一、范围、枚举、正则、长度、时效、字段级自定义 SQL

预置规则只读。点击“复制”可以生成一份自定义规则，再修改参数或说明。

规则包含：

| 字段 | 说明 |
|------|------|
| 规则名称 | 业务可读名称 |
| 规则编码 | 租户内唯一编码 |
| 规则级别 | 表级 / 字段级，由规则类型决定 |
| 规则类型 | 非空、唯一、范围等 |
| 严重级别 | ERROR 不达标任务失败；WARN 只记录告警 |
| 默认参数 | 规则库中的默认参数，任务绑定时可覆盖 |

## 二、创建检核任务

进入 **数据质量 → 质量检核**，点击“新建检核任务”。

1. 选择数据源、Schema、表；
2. 可选填写过滤条件，例如 `created_at >= '2026-01-01'`；
3. 添加规则：
   - 从规则库选择规则；
   - 字段级规则选择字段；
   - 组合唯一规则选择多个字段；
   - 配置规则参数、严重级别和阈值；
4. 配置抽样行数；结果格式和输出目录使用系统默认值；
5. 保存后点击“立即执行”。

阈值含义：

- `无效行数 ≤`：允许的最大无效行数，默认 0；
- `比例 ≤`：允许的最大无效比例，默认 0；
- 两个条件同时满足才判定通过。

## 三、查看结果

在任务列表点击“结果”：

- 查看整体状态：通过 / 告警 / 不通过；
- 查看规则级无效行数、比例和说明；
- 下载汇总文件；
- 对失败规则下载问题数据抽样明细。

结果文件保存在文件存储中：

```text
data-quality/<任务ID>/<执行实例>/quality_summary.csv
data-quality/<任务ID>/<执行实例>/quality_detail_1_<规则>.csv
```

本地存储默认在 `data/files/tenants/<租户>/` 下，也可以在文件管理中浏览；使用 MinIO 时写入对应 bucket。

## 四、在 ETL 中使用数据质量组件

ETL 设计器组件面板中新增 **数据质量检核** 组件。

- `FLOW` 模式：直接检核上游数据，可以放在流程中间透传数据；
- `TABLE` 模式：检核指定 DuckDB 表，适合上游已经物化的场景。

当 ERROR 规则不达标时，组件会抛出异常，当前 ETL 任务标记为失败。结果文件同样写入文件存储。

详细参数见 [DataQualityCheck 组件](../components/DataQualityCheck.md)。
