# 使用指南

本指南按**功能模块**介绍 DataY 平台的使用方法。建议先按顺序通读一遍，再按需查阅。

## 功能模块总览

| 模块 | 你能用它做什么 | 指南 |
| --- | --- | --- |
| 数据源管理 | 注册数据源、测试连接、浏览 schema / table / column 元数据 | [数据源管理](guide/datasource.md) |
| 数据集成与同步 | 拖拽 ETL 画布或可视化选表，把源数据同步进数仓 | [数据集成与同步](guide/integration.md) |
| 任务设计与开发 | 定义并编排 ETL、SQL、Shell、DAG 等任务 | [任务设计与开发](guide/development.md) |
| 任务调度与实例 | Cron 调度、依赖调度、上线 / 下线、实例监控 | [任务调度与实例](guide/scheduler.md) |
| 维度建模 | 定义维度 / 事实表与关联关系，构建星型模型 | [维度建模](guide/modeling.md) |
| 指标管理 | 定义原子指标、衍生指标，统一业务口径 | [指标管理](guide/metric.md) |
| 智能问数 | 用自然语言直接取数，无需编写 SQL | [智能问数](guide/askdata.md) |

## 典型操作流程

```
① 注册数据源 ─▶ ② 数据集成 / 同步 ─▶ ③ 维度建模 ─▶ ④ 指标管理 ─▶ ⑤ 智能问数 / 查询
   datasource       integration        modeling       metric          askdata
```

1. **数据源管理**：先把源库、目标库都注册进来，并测试连通。
2. **数据集成与同步**：选择数据源，编排任务把数据同步进数仓物理表。
3. **维度建模**：在数仓之上定义维度与事实模型，赋予业务语义。
4. **指标管理**：基于事实表定义指标口径，供报表与问数统一使用。
5. **数据应用**：用智能问数或公共指标查询面板取数。
