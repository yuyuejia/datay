四步用起来

先看模板属于哪一类，再走对应的导入入口。

1

下载模板

在下方模板列表选择场景，点击「下载模板」得到 JSON 文件。

2

选择导入入口

ETL 单任务从「数据集成」导入；完整应用从「应用市场」导入。

3

配置数据源

按模板提示创建或选择数据源，修改表名、连接地址和账号密码。

4

执行或上线

先执行一次验证数据，再按需配置 Cron 上线调度。

批量同步

最基础的库表全量同步：从 MySQL 源库读取整表，覆盖写入 MySQL 目标库，目标表不存在时自动建表。

MySQL→ StreamJdbcInput→ StreamJdbcOutput→ MySQL
前置条件
MySQL 5.7+，源表可读，目标库可写
导入后
核对源/目标数据源、schema 和表名
